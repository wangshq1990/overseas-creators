# 文化适配指南（Cultural Fit Guide）

> 团队自有领域知识 · 由「海外趋势与文化适配官」韦风宜在文化适配审查时使用。
> 本指南区别于用户提供的 **IP 声线 / 人设**（那是用户资产）。本指南解决的是"内容在北美 / 欧洲落不落得了地"，与"用谁的语气说"无关。

---

## 0. 总原则：先理解，再借势

水土不服的本质，是用**创作者的本地语境**去硬套**目标市场语境**。本指南要求所有对外内容在发布前过三道关：

- **口味关（Taste）**：当地受众感不感兴趣、会不会觉得"尬"或"自嗨"。
- **审美关（Aesthetics）**：视觉与节奏是否符合当地平台习惯。
- **价值观关（Values）**：会不会无意冒犯、踩雷、引发争议。

三关任一出现 🔴，禁止发布；出现 🟡，须修改后复检。

---

## 1. 目标市场速览

| 维度 | 北美（美 / 加） | 欧洲（英 / 德 / 法 / 西等） |
|------|----------------|------------------------------|
| 默认英语口径 | 美式英语（en-US） | 英式 / 欧陆英语（en-GB），用词与拼写不同 |
| 幽默风格 | 自嘲、直白、meme 密度高 | 更含蓄、反讽（dry / sarcastic），忌过度热情 |
| 价值观敏感 | 种族、枪支、医保、身份政治极敏感 | 殖民历史、移民、福利、宗教更敏感 |
| 节日节点 | 超级碗、万圣节、感恩节、独立日、黑色星期五 | 足总杯 / 欧洲杯、诸圣节、跨年、各国国庆 |
| 平台偏好 | TikTok / YouTube / X 强势 | 英法 X 与 Instagram 活跃，TikTok 受监管更严 |

> 英语内容**默认北美口径**；明确面向欧洲时，须标注"欧洲版"并替换用词、节日与举例。

---

## 2. 口味（Taste）

### 2.1 当地真正吃香的内容特征
- **具体胜过宏大**：一个真实小故事 > 抽象大道理。海外受众对"说教感"容忍度低。
- **自我披露与脆弱感（vulnerability）**：适度分享失败、纠结、学习过程，比"完美人设"更可信（尤其 YouTube / 个人 IP）。
- **实用价值优先**：教程、清单、对比、避坑——"能拿走用"的内容转化与留存最好。
- **参与感钩子**：提问、二选一、评论区投票，比单向输出更易起量。

### 2.2 容易"水土不服"的口味雷区
- ❌ 内圈梗外溢：只有华语圈懂的梗直接翻译，当地受众无感甚至困惑。
- ❌ 自嗨式成就展示：高频"我们多厉害"在个人 IP 场景易显傲慢，应改为"我踩过的坑 / 我怎么做的"。
- ❌ 过度集体主义叙事：欧美个人 IP 更强调个体选择与自主，慎用"大家都要……"式表达。
- ❌ 把争议当流量：未经验证的争议话题借势，极易翻车（见 §4）。

---

## 3. 审美（Aesthetics）

### 3.1 平台审美基线
- **TikTok / Reels / Shorts**：前 1–3 秒强钩子、快切、字幕常驻、竖版 9:16；克制使用花字与转场。
- **Instagram 轮播**：首图即结论、留白充足、统一字体与配色、第 1/末张强 CTA。
- **YouTube 缩略图**：高对比、大字标题、真人表情特写；避免信息过载与低清。
- **X(Twitter) thread**：每段一个论点、配图 ≤1、克制表情符号、引用可核验来源。
- **信息图 / 长图**：图表化、少文字、配色符合品牌规范；避免大段中文式排版的密集感。

### 3.2 审美雷区
- ❌ 中式审美硬套：大红大金满版、密集文字、过度装饰——在多数海外平台显"广告感 / 廉价感"。
- ❌ 字体与版式错位：避免中文字体用于英文、避免衬线过度正式（除非 IP 定位本就高端）。
- ❌ 配色文化误读：如紫色在部分语境关联哀悼；绿色在中东关联特定宗教——跨区发布前核对。

## 4. 价值观（Values）与安全分级

### 4.1 文化安全三级
- 🟢 **安全**：生活方式、技能教学、娱乐、产品体验、普世情感。
- 🟡 **谨慎**：社会议题、节日商业化、身体 / 外貌话题、对比"哪国更好"——可碰但需措辞把关、不站队、不绝对化。
- 🔴 **高危（禁止借势）**：政治选举与党派、武装冲突、种族 / 宗教 / 性别对立、悲剧事件营销、未经核实的突发新闻、文化挪用。

### 4.2 高危红线（务必规避）
- **文化挪用（cultural appropriation）**：把少数族裔 / 原住民的文化符号当装饰或噱头，且无理解与尊重。借用时须注明来源、避免商业化冒犯。
- **刻板印象**：对国家、性别、年龄、职业的扁平化标签（如"某国人都会……"）。
- **悲剧 / 灾难营销**：借伤亡、自然灾害、社会悲剧引流，几乎必然反噬。
- **未经核实的热点**：突发新闻在事实未明前借势，易被证伪后打脸。
- **节日误用**：把当地严肃节日（如阵亡将士纪念日、诸圣节）做成轻浮促销。

### 4.3 价值观表达建议
- 立场模糊但**尊重底线**：可表达普世价值（诚实、善意、努力），不卷入撕裂性对立。
- 用"我的经验 / 我的选择"代替"你应该"——降低说教与冒犯感。
- 涉及多元群体时，使用中性、包容的称谓与表述。

---

## 5. 借势操作清单（热点来了怎么用）

1. 先判级：🟢 / 🟡 / 🔴（§4.1）。
2. 🔴 直接放弃，记录原因备查。
3. 🟡 借势但：不站队、不绝对化、注明角度、规避具体人物与组织。
4. 所有借势先落到**图文核心**（遵循团队图文核心公理），再派生视频。
5. 成稿必须过 §2–§4 三关审查，出具《文化适配审查单》后方可进入主理人终审。

## 6. 常见水土不服案例（速查）

| 现象 | 根因 | 修正 |
|------|------|------|
| 翻译腔、机翻感重 | 直译中文表达 | 按 en-US / en-GB 习惯重写，保留意而非字 |
| 内容"很努力但没人看" | 自嗨 / 说教 / 缺实用价值 | 改为具体故事 + 可拿走的价值 |
| 视觉被评"像广告" | 中式满版审美 | 留白、克制配色、统一字体 |
| 借势翻车 | 踩政治 / 悲剧 / 挪用红线 | 判级 🔴 即弃，不赌概率 |
| 欧洲受众冷淡 | 用了美式举例 / 节日 | 出"欧洲版"，替换语境 |

> 本指南为团队基线，应随市场变化由韦风宜持续更新。更新须经主理人确认，并同步告知内容策划官。
